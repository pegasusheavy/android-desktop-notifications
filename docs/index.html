Installing the Android App

The app isn't on the Play Store yet, so you'll need to sideload the APK. Here's how:

1

Download the APK

Go to the latest release and download notisync-*-debug.apk to your phone.

2

Allow Installation from Unknown Sources

When you tap the APK, Android will prompt you to allow installing from your browser or file manager. Tap Settings → enable Allow from this source → go back.

3

Install the APK

Tap Install when prompted. If you see a Play Protect warning, tap More details → Install anyway.

4

Grant Notification Access

Open NotiSync and tap Grant Permission. This takes you to Android settings. Find NotiSync in the list and enable it. Confirm the warning dialog.

5

Disable Battery Optimization (Recommended)

For reliable background operation, tap Disable Battery Optimization in the app and allow NotiSync to run unrestricted. This prevents Android from killing the app when your screen is off.

Tip: Make sure your phone and desktop are on the same WiFi network. The app will automatically find and connect to your desktop.

Installing the Desktop App

Windows

Download and run the MSI installer. The app starts automatically on login.

notisync-windows-x86_64.msi

macOS

Open the DMG and drag NotiSync to Applications. Run from Launchpad.

notisync-*-macos-universal.dmg

Linux

Install via your package manager or use the systemd service.

sudo dpkg -i notisync_*.deb yay -S notisync
